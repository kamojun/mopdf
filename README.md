# mopdf

PDFの**目次（Table of Contents）** と **ページラベル** をGUIで編集・保存できるデスクトップアプリです。

## 機能

### PDF閲覧

- スクロール連動の遅延レンダリング（表示範囲＋前後2ページのみを非同期で描画）
- ドラッグ&ドロップ、最近使ったファイル、コマンドライン引数からPDFを開く
- 各ページ下部にページラベルと物理ページ番号を表示
- 右クリックメニューから「テキスト選択し目次追加」「ページへ移動」「この位置にページラベル追加」
- テキスト選択モード：ページ上をドラッグしてタイトルを取得し、そのまま目次に追加

### 目次編集

- 階層ツリー表示。エントリの追加・削除・並び替え・階層変更（ツールバー操作、ドラッグ&ドロップ、`Tab`/`Shift+Tab`）
- 複数選択した項目をまとめて移動・階層変更
- テキスト選択モードでPDFからタイトルを取得して追加
- 目次とページラベルを一本化したUndo履歴（`Ctrl+Z`、最大50件）
- ページ番号未設定（`?`）状態、ページ番号の連続入力モード（Enterで次行に自動移動、加算値を提案）
- CSV入出力（`level,title,page` / `title,page` の2〜3列形式に対応、ページはラベル文字列・`(物理ページ)`・整数のいずれも解決可能）
- プレーンテキスト(.txt)インポート、クリップボードからの貼り付けインポート（`Ctrl+V`）
- CSV/TXTファイルのドラッグ&ドロップインポート

### ページラベル編集

- アラビア数字・ローマ数字（大小）・英字（大小）・なし、の複数スタイルに対応
- プレフィックス・開始番号の指定、ツールバー操作やPDF右クリックからの追加・削除
- CSV入出力、CSVファイルのドラッグ&ドロップインポート
- ページラベル変更時、目次のページ表示を維持するか選択可能（更新する／ページ番号を維持する／キャンセル）

### ファイル操作

- 上書き保存（`Ctrl+S`、一時ファイル経由のアトミックな置換、暗号化・権限を維持）
- 別名で保存（`Ctrl+Shift+S`、元PDFの保護維持設定あり）
- 最近使ったファイル履歴（最大10件）
- ベースライン比較による未保存変更の検出、変更点の一覧表示（`Ctrl+D`）
- 閉じる確認ダイアログ（キャンセル／保存せずに閉じる／保存して閉じる、変更点の詳細表示付き）
- パスワード保護されたPDFは開けない旨を表示（未対応）

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Ctrl+O` | 開く |
| `Ctrl+S` | 保存 |
| `Ctrl+Shift+S` | 別名で保存 |
| `Ctrl+V` | 目次をクリップボードから貼り付け |
| `Ctrl+Z` | 元に戻す（目次・ページラベル共通） |
| `Ctrl+D` | 変更点を表示 |
| `Ctrl+/` | キーボードショートカット一覧を表示 |
| `Ctrl+Q` | 終了 |
| `Esc` | テキスト選択モードをキャンセル |

目次ツリー上でのショートカット：

| キー | 動作 |
| --- | --- |
| `↑` / `↓` | 選択移動（該当ページへジャンプ） |
| `Shift+↑` / `Shift+↓` | 複数選択（ページジャンプなし） |
| `Alt+↑` / `Alt+↓` | ページ追従せず選択のみ移動 |
| `Ctrl+↑` / `Ctrl+↓` | 選択項目を上下に並べ替え |
| `Tab` / `Ctrl+→` | 階層を下げる（インデント） |
| `Shift+Tab` / `Ctrl+←` | 階層を上げる（アウトデント） |
| `Enter` | 選択項目を編集 |
| `Shift+Enter` | 選択項目の上に新規項目を挿入 |
| `Ctrl+Enter` | 選択項目の下に新規項目を挿入 |
| `Delete` / `Backspace` | 選択項目を削除 |

すべてのショートカットは「ヘルプ→キーボードショートカット...」からも確認できます。

## インストール

```bash
git clone https://github.com/kamojun/mopdf.git
cd mopdf
pip install -r requirements.txt
```

**依存関係**

- Python 3.10+
- [PyMuPDF](https://pymupdf.readthedocs.io/) >= 1.23.0
- [PySide6](https://doc.qt.io/qtforpython/) >= 6.6.0

## 使い方

```bash
python main.py
```

PDFファイルをドラッグ&ドロップするか、メニューから「開く」で読み込んでください。

## macOS向けスタンドアローンアプリのビルド

Python環境なしで起動できる `mopdf.app` をPyInstallerでビルドできます。

```bash
pip install -r requirements-dev.txt
pyinstaller mopdf.spec
open dist/mopdf.app
```

- `dist/mopdf.app` が生成されます。アイコンを更新する場合は `assets/icon.png` を差し替えて `python scripts/make_icon.py` を再実行してください（Pillowが必要です）。
- 未署名・未公証のアプリのため、初回起動時はFinderで`mopdf.app`を**右クリック→「開く」**を選んでください（ダブルクリックだけだとGatekeeperにブロックされます）。
