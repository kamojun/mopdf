# mopdf

**PDFの「目次」を編集するためのデスクトップアプリです。**

PDFを見ながら、しおり（アウトライン）とページ番号の振り方を直接編集し、同じPDFに書き戻せます。
ページの追加・削除・結合や、本文の編集はできません。**目次まわりの編集に特化したツール**です。

スキャンした資料や、目次情報を持たないPDFなどに、
あとから使える目次を付け直す用途を想定しています。

---

## ダウンロード（ビルド済みアプリ）

Python環境を用意せずに使いたい場合は、[Releases](https://github.com/kamojun/mopdf/releases/latest) からビルド済みのアプリをダウンロードできます。

| ファイル | 対象 |
| --- | --- |
| `mopdf-vX.Y.Z-macos-arm64.zip` | Apple Silicon搭載Mac（M1以降） |

zipを展開して `mopdf.app` を「アプリケーション」フォルダへ移動してください。

**初回起動時の注意（未署名アプリのため）**

Apple Developer Programの署名・公証を行っていないため、ダウンロードしたアプリはそのままでは起動できません。ターミナルで以下を実行して隔離属性を外してください。

```bash
xattr -dr com.apple.quarantine /Applications/mopdf.app
```

ターミナルを使わない場合は、一度ダブルクリックして警告が出たあとに「システム設定 → プライバシーとセキュリティ」を開き、下部に表示される「このまま開く」を選んでください。

> macOS 15 (Sequoia) 以降では、右クリック→「開く」による回避はできなくなっています。

## インストール（ソースから）

```bash
git clone https://github.com/kamojun/mopdf.git
cd mopdf
pip install -r requirements.txt
```

**依存関係**

- Python 3.10+
- [PyMuPDF](https://pymupdf.readthedocs.io/) >= 1.23.0
- [PySide6](https://doc.qt.io/qtforpython/) >= 6.6.0

## 使い方

ビルド済みアプリなら `mopdf.app` を起動します。ソースから使う場合は次を実行してください。

```bash
python main.py
```

PDFファイルをドラッグ&ドロップするか、メニューから「開く」で読み込んでください。

目次のページ番号をどう入力すればよいかは「[ページ番号の考え方](#ページ番号の考え方)」を読んでください。ほとんどの場合、そこだけ分かれば使えます。

## PDFの「目次」は2つの要素でできている

PDFで「目次」と呼ばれるものは、実は**独立した2つの仕組み**です。
mopdfは、この両方を編集できます。

| | TOC（アウトライン） | ページラベル |
| --- | --- | --- |
| 別名 | しおり、ブックマーク、目次 | 論理ページ番号、Page Labels |
| 見える場所 | ビューアの左サイドバーの階層リスト | ビューアのページ番号入力欄 |
| 役割 | 「タイトル → ページ」のジャンプ表 | 「何ページ目をどう呼ぶか」の命名規則 |
| 構造 | 階層を持つツリー | ページ範囲ごとの書式定義 |

この2つは連動していません。片方だけが設定されているPDFもよくあります。

### 1. TOC（アウトライン / しおり）

PDFビューアを開いたときに、左側のサイドバーに出てくる**階層つきの目次**のことです。
Adobe Acrobatでは「しおり」、ブラウザのPDFビューアでは「ドキュメントの概要」などと呼ばれます。

TOCの1エントリは、次の3つを持ちます。

- **階層（level）** … 第1階層＝章、第2階層＝節、といったネストの深さ
- **タイトル（title）** … 表示される文字列
- **ページ（page）** … クリックしたときに飛ぶ先のページ

```
1  第1章 はじめに ......... 1
2    1.1 背景 ............. 3
2    1.2 目的 ............. 7
1  第2章 実装 ............. 12
```

mopdfでは、これを右側のツリーで編集します。項目の追加・削除・並び替え・階層変更、
PDF本文から文字列を選択してタイトルとして取り込む、といった操作ができます。

### 2. ページラベル

PDFの各ページに付く**「表示上のページ番号」の定義**です。

紙の本には、前書きが `i, ii, iii...`、本文が `1, 2, 3...`、
付録が `A-1, A-2...` のように、通し番号ではない番号が振られていることがあります。
ページラベルは、これをPDF上で再現する仕組みです。

ページラベルは1ページずつ設定するのではなく、**「ここから先はこの書式」という範囲の連なり**で定義します。
1つの範囲は次の4つを持ちます。

- **開始ページ** … この書式が始まる物理ページ
- **スタイル** … アラビア数字 / ローマ数字（大・小）/ 英字（大・小）/ なし
- **プレフィックス** … 番号の前に付ける文字列（例: `A-`）
- **開始番号** … その範囲の先頭を何番から数え始めるか

例えば次のように定義すると、

| 開始ページ | スタイル | プレフィックス | 開始番号 |
| --- | --- | --- | --- |
| 1 | ローマ数字（小） | (なし) | 1 |
| 5 | アラビア数字 | (なし) | 1 |
| 30 | アラビア数字 | `A-` | 1 |

実際のページ番号はこうなります。

```
物理ページ:  1   2    3    4    5   6   7  ...  30    31    32
ページラベル: i   ii   iii  iv   1   2   3  ...  A-1   A-2   A-3
```

ページラベルを設定しておくと、ビューアのページ番号入力欄に `iii` や `A-1` と打って
そのページへ移動できるようになります。

## ページ番号の考え方

ここは身構えなくて大丈夫です。**やることは、次の2パターンのどちらかだけ**です。

### 書籍のPDFなら：ページラベルを先に設定する

1. **先にページラベルを設定する**（前書きは `i, ii, iii...`、本文は `1` から、など）
2. あとは、**紙の本の目次に印刷されているとおりのページ番号**をそのまま入力する

これだけです。目次に「第3章 …… 47ページ」と書いてあるなら、`47` と入力すれば正しく飛びます。
前書きが何ページあるか数えて足し算する、といった作業は要りません。
そのためのページラベルです。

（順番だけ気をつけてください。**ページラベル → 目次のページ番号**の順で作業するのが確実です。
逆順でも、ページラベル変更時に「目次のページ表示を更新する／維持する」を選ぶダイアログが出ます。）

### 書籍でないなら：何も気にしなくてよい

資料・レポート・スライドなど、ページラベルを使わないPDFでは、
**PDFの先頭から数えた番号をそのまま入力するだけ**です。
1ページ目が `1`、10ページ目が `10`。それで正しく動きます。
ページラベルのパネルは触らなくて構いません。

### 詳しい仕組み（つまずいたときに）

上の2パターンで足りていれば、ここは読み飛ばして大丈夫です。

PDFには2種類のページ番号があります。

- **物理ページ** … PDFの先頭から数えた実際の順番。必ず `1, 2, 3, ...` と連番になる
- **表示ページ（ページラベル）** … ページラベルの定義で決まる「見かけの番号」。`i` や `A-1` のような文字列にもなり、連番とは限らない

```
       ┌─────┬─────┬─────┬─────┬─────┬─────┬─────┐
物理:  │  1  │  2  │  3  │  4  │  5  │  6  │  7  │  ← 常に連番・不変
       ├─────┼─────┼─────┼─────┼─────┼─────┼─────┤
表示:  │  i  │ ii  │ iii │ iv  │  1  │  2  │  3  │  ← ページラベル次第
       └─────┴─────┴─────┴─────┴─────┴─────┴─────┘
                              ↑
                    ここで書式が切り替わる
```

TOCのジャンプ先としてPDFに保存されるのは、常に**物理ページ**です。
それでも紙の本どおりの番号を入力すればよいのは、mopdfが入力を次の順で解釈して、
表示ページを物理ページに翻訳しているからです。

1. まず**ページラベルとして**探す（`iii`、`A-1`、`12` など）
2. 見つからなければ、`(12)` のような**丸括弧つきの数字を物理ページ**として解釈
3. それでも該当しなければ、**数字を物理ページ**として解釈（フォールバック）
4. `?` は「ページ未設定」

ページラベルを設定していないPDFでは1と2が空振りして3だけが効くので、
結果として「入力した数字＝物理ページ」になります。これが「何も気にしなくてよい」理由です。

覚えておくと便利なのは、**物理ページで指定したいときは `(12)` のように丸括弧を付ける**ことです。
括弧なしの数字は、まずページラベルとして探しに行きます。

なお、PDFビューアの各ページ下部には表示ページと物理ページの両方が出ているので、
迷ったらそこを見れば確認できます。

> 同じラベルが複数ページに存在する場合は、**先頭から最初に一致した物理ページ**が採用されます。

## インポート / エクスポート

紙の本の目次を書き起こす、他のツールで作った目次を持ち込む、といった場合に使います。
すべてのファイルは **UTF-8** で読み書きします（書き出しはBOM付き）。

### TOCのインポート形式

`.txt` と `.csv` の2種類を受け付けます。ツールバーのインポートボタン、
またはファイルを目次パネルに**ドラッグ&ドロップ**して読み込みます。

インポートは既存の目次を**置き換えます**（実行前に確認ダイアログが出ます）。

#### `.txt` — タイトルだけの一覧

**1行1タイトル**のプレーンテキストです。空行は無視されます。

```
第1章 はじめに
1.1 背景
1.2 目的
第2章 実装
```

すべて**第1階層・ページ未設定（`?`）**として取り込まれます。
階層とページはあとからGUIで付けていく前提の、一番手軽な形式です。

紙の目次をOCRしたテキストや、Webページからコピーしたリストをそのまま流し込むのに向いています。
同じ形式は**クリップボードからの貼り付け（`Ctrl+V`）**でも使えます。
こちらは既存の目次を消さず、選択中の項目の直後に挿入します。

#### `.csv`（3列） — `level,title,page`

階層・タイトル・ページをすべて指定する、完全な形式です。書き出しもこの形式です。

```csv
level,title,page
1,第1章 はじめに,1
2,1.1 背景,3
2,1.2 目的,7
1,第2章 実装,12
```

- **`level`** … 階層。`1` が最上位。1以上の整数
- **`title`** … タイトル文字列
- **`page`** … ページ指定。上の「[詳しい仕組み](#詳しい仕組みつまずいたときに)」と同じルールで解釈されます
  - `12` … まずページラベル `12` を探し、なければ物理ページ12
  - `iii` / `A-1` … ページラベルとして解決
  - `(12)` … 物理ページ12（1始まり）
  - `?` … ページ未設定

#### `.csv`（2列） — `title,page`

階層を使わない、フラットな目次向けの短縮形です。全エントリが**第1階層**になります。

```csv
title,page
第1章 はじめに,1
第2章 実装,12
```

#### CSV共通のルール

- **列数で形式が決まります。** 3列以上なら `level,title,page`、ちょうど2列なら `title,page` として読まれます。1列しかない行はスキップされます
- **ヘッダー行は自動で読み飛ばされます。** 1列目が `level`（3列の場合）または `title`（2列の場合）の行が対象です。ヘッダーは省略しても構いません
- **`#` で始まる行はコメント**として無視されます
- **解決できなかったページは未設定（`?`）として取り込まれ**、インポート後に警告ダイアログで該当行が一覧表示されます。読み込み自体は失敗しないので、GUIで修正してください
- **ページ数を超える指定は最終ページに丸められ**、同じく警告されます

### TOCのエクスポート形式

常に `level,title,page` の**3列CSV**（ヘッダー付き）で書き出されます。

`page` 列は、そのPDFの状態に応じて次のように書かれます。

| 条件 | 出力される値 |
| --- | --- |
| ページ未設定 | `?` |
| ページラベルがないPDF | 物理ページ番号（1始まり） |
| ページラベルがあるPDF | そのページのラベル文字列 |
| ページラベルはあるが、そのページのラベルが空 | `(物理ページ番号)` |

書き出したCSVはそのまま読み戻せます。

### ページラベルのインポート / エクスポート

ページラベルは `.csv` のみ対応で、列は **`start_page,style,prefix,first_num` の4列固定**です。

```csv
start_page,style,prefix,first_num
1,r,,1
5,D,,1
30,D,A-,1
```

- **`start_page`** … その書式が始まる**物理ページ**（1始まり）。PDFのページ範囲内であること
- **`style`** … スタイルコード。下表のいずれか
- **`prefix`** … 番号の前に付ける文字列。空でも可
- **`first_num`** … その範囲の開始番号（整数）

| コード | スタイル | 出力例 |
| --- | --- | --- |
| `D` | アラビア数字 | `1, 2, 3` |
| `r` | ローマ数字（小） | `i, ii, iii` |
| `R` | ローマ数字（大） | `I, II, III` |
| `a` | 英字（小） | `a, b, c` |
| `A` | 英字（大） | `A, B, C` |
| （空） | なし | プレフィックスのみ |

ヘッダー行（1列目が `start_page`）と `#` で始まるコメント行は読み飛ばされます。
4列に満たない行はスキップされ、値が不正な行（範囲外のページ、未知のスタイルコードなど）は
スキップしたうえで警告ダイアログに一覧表示されます。

## 機能一覧

### PDF閲覧

- スクロール連動の遅延レンダリング（表示範囲＋前後2ページのみを非同期で描画）
- ドラッグ&ドロップ、最近使ったファイル、コマンドライン引数からPDFを開く
- 各ページ下部にページラベルと物理ページ番号を表示
- 右クリックメニューから「テキスト選択し目次追加」「ページへ移動」「この位置にページラベル追加」
- テキスト選択モード：ページ上をドラッグしてタイトルを取得し、そのまま目次に追加
- ズーム/フィット表示：デフォルトはウィンドウ高さに合わせた自動フィット。表示メニューでの拡大/縮小/実際のサイズ、トラックパッドのピンチズームにも対応し、手動ズーム後は「ウィンドウに合わせる」で自動フィットに復帰。ステータスバーに現在のズーム%を表示
- ページ番号ラベルをクリックすると「ページへ移動」ダイアログを開ける

### 目次（TOC）編集

- 階層ツリー表示。エントリの追加・削除・並び替え・階層変更（ツールバー操作、ドラッグ&ドロップ、`Tab`/`Shift+Tab`）
- 複数選択した項目をまとめて移動・階層変更
- テキスト選択モードでPDFからタイトルを取得して追加
- `Ctrl+F` でのタイトル検索・フィルター（検索中はツリー編集をロック）
- ページ番号未設定（`?`）状態、ページ番号の連続入力モード（Enterで次行に自動移動、加算値を提案）
- CSV/TXTインポート、CSVエクスポート、クリップボード貼り付け（`Ctrl+V`）、ファイルのドラッグ&ドロップ

### ページラベル編集

- アラビア数字・ローマ数字（大小）・英字（大小）・なし、の複数スタイルに対応
- プレフィックス・開始番号の指定、ツールバー操作やPDF右クリックからの追加・削除
- CSV入出力、CSVファイルのドラッグ&ドロップインポート
- ページラベル変更時、目次のページ表示を維持するか選択可能（更新する／ページ番号を維持する／キャンセル）

### 共通

- 目次とページラベルを一本化したUndo/Redo履歴（`Ctrl+Z` / `Ctrl+Shift+Z`、最大50件）

### ファイル操作

- 上書き保存（`Ctrl+S`、一時ファイル経由のアトミックな置換、暗号化・権限を維持）
- 別名で保存（`Ctrl+Shift+S`、元PDFの保護維持設定あり）
- 最近使ったファイル履歴（最大10件）
- ベースライン比較による未保存変更の検出、変更点の一覧表示（`Ctrl+D`）
- 閉じる確認ダイアログ（キャンセル／保存せずに閉じる／保存して閉じる、変更点の詳細表示付き）
- パスワード保護されたPDFは開けない旨を表示（未対応）

| キー | 動作 |
| --- | --- |
| `Ctrl+O` | 開く |

## macOS向けスタンドアローンアプリのビルド

Python環境なしで起動できる `mopdf.app` をPyInstallerでビルドできます。

```bash
pip install -r requirements-dev.txt
pyinstaller mopdf.spec
open dist/mopdf.app
```

- `dist/mopdf.app` が生成されます。アイコンを更新する場合は `assets/icon.png` を差し替えて `python scripts/make_icon.py` を再実行してください（Pillowが必要です）。
- 自分でビルドした `mopdf.app` はそのまま起動できます（隔離属性が付かないため、ダウンロード版で必要な`xattr`の操作は不要です）。
- 配布用にzipへ固める場合は `ditto -c -k --sequesterRsrc --keepParent dist/mopdf.app mopdf.zip` を使ってください（`zip`コマンドはアプリバンドル内のシンボリックリンクを壊すことがあります）。
